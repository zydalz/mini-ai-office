# 🚀 Mini AI Office — Pixel Space Agency

> Antarmuka kantor virtual agen AI mandiri (*autonomous multi-agent*) berbasis web dengan estetika **Cozy Pixel Art x Futuristic Clean Space**.

---

## 🌟 Fitur Utama
* **3 Agen Kolaboratif:**
  * 🧑‍💼 **Nova (Lead Architect & PM):** Analisis instruksi & pembagian tugas.
  * 💻 **Spark (Full-Stack Builder):** Implementasi kode & solusi.
  * 🕵️ **Echo (QA & Reviewer):** Pengujian, deteksi bug, dan approval akhir.
* **Tampilan Interaktif:** Kantor stasiun luar angkasa dengan avatar pixel, meja konsol, dan holo-table.
* **100% Gratis & Serverless:** Menggunakan Google Gemini 1.5 Flash API via client-side storage.
* **Vercel Ready:** Static site tanpa dependensi rumit, siap di-deploy secara instan.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Modern Vanilla CSS, ES Modules JavaScript.
* **AI Model:** Google Gemini 1.5 Flash API.
* **Deployment:** Vercel.
